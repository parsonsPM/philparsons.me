# philparsons.me

Personal site for Phil Parsons, built with [Astro](https://astro.build) and deployed on Cloudflare Pages.

All copy lives in `src/data/site.json`. Sections with no copy are left out of the page.

```sh
npm install
npm run dev     # local preview at http://localhost:4321
npm run build   # static build into dist/
```
